# 0.8.2 网页精简交接

## 目标与边界

0.8.2只精简网页信息架构，不修改`DebugWebServer` API、Flash分段发送、Ctrl/Board/Driver/Preferences、NVS格式或运动状态机。未烧录、未访问板卡/串口、未发送真实PWM或写真实NVS。

## 页面结构

- 全局始终显示状态、站立、停止、关闭输出和统一反馈；停止保持力矩，关页不会自动停，关闭输出不是物理急停。
- 控制页使用唯一Walk/Trot选择，同时服务手动启动和方向pad；四常用参数与慢速/Walk/Trot预设直接可见。
- 姿态与水平校准、CG/移动补偿、Profile、手动预检、单腿和原始命令遥测均默认收起。隐藏高级草稿仍锁定启动并在主界面提示。
- 标定页主流程为安全确认→开始→选择接口→中位±1°→保存并退出。开始回当前已存/内存中位，不会重置固定90°；原始us、q、相对偏移和单路调试位于高级折叠。

## 行为保持

- Stand按钮在OFF状态发送`arm_stand`，已ARM时发送`stand`；状态未知时不发送。
- Walk/Trot预设同步唯一步态选择，但只改草稿；启动仍要求显式应用并由固件自动完整预检。
- 切换视图、展开、选通道、拖动、编辑和轮询零动作；若方向键正被长按，切视图会显式结束本次会话。
- 标定保存调用原`cal_save_all`，先全关再保存；本地mock只更新进程内状态并明确不写NVS。

## 验证

- `test/host/run_all_tests.ps1`以`-Wall -Wextra -Werror`全套exit 0。新增覆盖双视图默认状态、DOM id唯一、桌面/手机结构、Stand分支、状态未知零写、dirty/save门控、CG显式应用、标定保存退出和视图切换方向释放。
- 真实内嵌页面为71,382 UTF-8 bytes；Flash响应测试逐字节验证当前页面，另以独立65,536字节旧路径样本复现String失败，并保留128 KB模板回归。
- 本地mock在桌面与390×844手机viewport完成：Walk预设→应用→站立→Walk→停止；八路标定→Servo12 +1°→91°/1511µs→保存退出并全关；隐藏高级参数dirty提示与启动锁定。手机内容宽度无横向溢出（`scrollWidth==clientWidth==375`），四项常用参数保持2×2。
- 最终本地控制页截图保存为`results/v10-0.8.2-simple-control-local.jpg`；截图来自mock，不是真实板卡。
- PlatformIO 6.2.0 detect/list/build均exit 0，未clean/upload。最终`firmware.bin`为1,012,976 bytes，生成时间2026-10-08 22:00:40，SHA-256 `6DDDBEA1081F76A1CBE7403BD144959B051F2F266DC57490FB00B7F37791A077`。
