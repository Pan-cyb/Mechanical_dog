# 0.8.3 L3H Servo9→Servo13交接

## 目标

用户要求把L3H腿3右后大腿从丝印Servo9/PCA CH8移到Servo13/CH12；这不是ESP32 GPIO13。其他七路、方向、几何、速度/角度窗口、小腿表、预检和状态机均不变。

## 实现

- 八路顺序统一为`{0,1,2,3,12,9,10,11}`，索引4仍是L3H；snapshot动态发布Servo13/CH12/L3H，校准mask为`0x1E0F`。
- `PreferencesCalibrationStore`由组合根传入read fallback `(new=12, legacy=8)`，Port不依赖Board。
- 加载c12时，已有c12无条件优先；仅c12键不存在时读取c8。值合法性继续由原`ChannelCalibration`判断，因此c12存在但非法时不会回退c8，而是默认90°。
- 加载与fallback不put/erase；显式保存CH12只写c12并保留c8。其余七个中位键、motion/profile记录不重释。

## 验证

- 先改测试期望映射，旧代码在`kSelectedServoChannels`第5项断言失败，exit1。
- `test/host/run_all_tests.ps1`严格全套exit0。正向覆盖协调PWM、八路标定、单路接口、relative offset、nudge/saveAll均落到CH12，CH8在机械狗通道池中拒绝且无新pulse；PCA底层任意通道和allOff测试保留。
- 新测试用host `Preferences` stub编译真实`PreferencesCalibrationStore.cpp`，覆盖c12优先、缺c12回退c8、非法/缺失默认、保存只写c12、begin/load零存储写和零PWM。
- 独立只读复审核对实际映射、真实Port键优先级、组合根注入与RobotApp仅版本变更，另行运行9个现有exe和Node均exit0，结论PASS。

## 实物步骤与未决问题

必须先断开舵机电源，再把L3H插头从Servo9拔下并插到Servo13，随后另行授权烧录0.8.3。代码变化不会自动改变板上固件或接线。

此前用户遇到的`Motion preflight failed`仍缺对应`/api/state`定位；0.8.3没有修复或放宽预检，也没有改变IMU超时。未访问板卡、串口或真实NVS。
