# 0.5.3 CH11 小腿 q 入口交接

日期：2026-09-30。状态：已构建、未烧录，未连接串口，未发送 PWM，未操作板上 NVS。

## 已完成范围

- 照片身份：腿4左后、Servo12、PCA CH11；拍照时中位命令100°。
- 照片候选节点：`(u,q)=(0,0),(30,9),(50,23)`，只做有界分段插值。
- 串口命令：`shank <ch> <q_deg>`；网页 POST 使用相同的 `CommandType::Shank` 和 `RobotApp` 后端。
- 只有 CH11 配置曲线，其他通道拒绝 q 命令。
- 运行路径：`q -> u -> offset=-u -> CH11当前标定中位 -> 原脉宽编码`。
- 可用 q 上限按当前中位、既有相对限位和0..180°电气范围实时计算；越界目标直接拒绝，不夹紧。
- 原有 offset、原始 PWM、中位微调/保存、八路标定和 NVS 格式不变。

## 安全边界

q 动作仍要求 IMU 新鲜、已 ARM 且处于单路模式。八路标定中、非法或非有限输入、未选入校准的通道、其他物理通道、电气越界和 PWM 故障均不增加运动。编辑草稿、选择通道、状态轮询和换算预览都不发送 PWM；全局 OFF 保留原网页优先路径。

q 是相对机械中位的小腿转角幅值，不是绝对膝角。照片曲线仍是候选，禁止自动复制到其他腿，也不能用于 IK 或步态。

## 验证证据

主机测试覆盖 `q=0/9/16/23 -> u=0/30/40/50`，中位100°时命令角为`100/70/60/50`，以及当前中位即时变化、CH11专属绑定和故障门控。中位37°时状态发布并接受`q_max=13.9°`，对应0°电气边界；13.91°和23°均拒绝且不夹紧。纯映射另覆盖往返换算、非法表和拒绝时不改出参；网页测试覆盖草稿零动作及 STOP 优先。
