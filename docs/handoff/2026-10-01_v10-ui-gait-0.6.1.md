# 0.6.1 V10 网页调参、持久化与步态衔接交接

日期：2026-10-01。范围：`mechanical_dog/` 与 `docs/`。前置备份：`.work/pre-v10-0.6.1-20261001-023606.zip`。**未烧录、未连接板卡、未发真实 PWM、未写板上 NVS。**用户只报告旧0.6.0实物大致能动，不作为本版验收。

## 本轮目标与结果

- 页面步态区移至顶部，草稿、板上RAM、NVS状态分开；未应用草稿锁定运动启动，应用成功需`/api/state`逐项回读，失败保留草稿。
- 参数可在idle/OFF、稳定Stand或Stop/Hold下应用/预检，调用零PWM且不改保持帧；运动/过渡/pending仍拒绝。应用只验证范围/有限数/Stand，开始或显式预检再检查目标模式整周期。
- 新增`arm_stand`原子语义：预检成功后ARM+排队Stand；失败不残留armed，命令自身零PWM，沿用新IMU首帧中位与1.5s过渡。旧`arm`仍只解锁单路台架。
- 新增独立`IMotionParameterStore`与ESP32 Preferences适配，命名空间`applepygait`、键`motion`；单一版本化完整记录含长度、六参数和校验，保存后回读。旧`applepycal/c{channel}`未改。
- 默认Trot起步6/2mm、1.2s；Walk预设6/2mm、2.5s；慢速通用预设3/1mm、3s。60°/s限速保持；合理不对称中位亦通过对应模式测试。
- 抬脚改为raised-cosine，起落端速度为0。预检5ms密采样且按真实dt计算，覆盖非20ms整数周期。运行维持20ms、无追帧爆发，并发布frame count、last/max gap、missed deadlines。
- 新增完整中文[网页使用指南](../WEB_UI_USER_GUIDE.md)。原V7.3的5ms tick、`speed=.05`/Trot计数回绕、Walk `speed/5`与重心等待只作为证据，未宣称完整复刻。

- 没有硬件PWM、供电、方向、负载、落地、网页真实网络阻塞或板上NVS实测。
