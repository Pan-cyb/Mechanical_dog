# 2026-09-28 六轴姿态显示交接

## 本轮目标与已知实板证据

用户希望在电脑/手机调试网页看到 Roll、Pitch、Yaw。原项目为 Py-Apple Dynamics V7.3 8DOF；现用实物是 ESP32-C3-WROOM-02-H4 + PCA9685 + HXY ICM-42688P 的 `Applepy_v1`。用户报告已成功烧录旧固件 `0.2.0`，启动串口记录 `PCA9685 0x40 ready; all channels OFF`、`HXY IMU 0x19 ID=0x6A ready`，并已连接 `Applepy-Debug` 热点。**不是**新 `0.3.0` 姿态角实测；暂无电源轨、轴向、PWM 或舵机实测记录。

## 原项目证据与工程判断

- `third_party/py-apple-servo/software/py-apple-dynamics/Py Apple Dynamics V7.3 SRC/PA-Dynamics V7.3/PA_IMU.py:15-65` 的 `IMUupdate` 只有加速度/陀螺六轴输入，`a[0..1]` 输出 Pitch/Roll 估计，没有输出 Yaw。
- M0 参考工程 `MSPM0G3507_CPP_Template/Legacy/IMU/IMU.c:335-369` 输出 Yaw/Pitch/Roll，但 `mygetqval[6..8]` 的磁向量未实际填入，磁场修正约第 262–292 行被注释；Yaw 只是相对陀螺积分，会漂移。其固定 `halfT=0.01f` 不应照搬到当前 100 Hz 采样。
- 现行 `mechanical_dog/src/Driver/HxyIcm42688p.cpp` 读取 `0x0C..0x17` 的三轴加速度和三轴角速度，转换为 `m/s²` 与 `rad/s`。对应 M0 `Legacy/ICM42688/icm42688.c:253-283` 的 HXY `0x19`/ID `0x6A`、100 Hz、±4g/±1000 dps 配置。PCA9685 是 PWM 输出，不测角度。没有磁力计、绝对航向或关节位置反馈。

## 新 `0.3.0` 软件及验证边界

- `mechanical_dog/include/Ctrl/AttitudeEstimator.h`、`src/Ctrl/AttitudeEstimator.cpp`：独立于 Arduino 的传感器坐标系六轴姿态估计。上电先收集 100 个相邻间隔 5–30 ms、加速度模长 0.9–1.1g、角速度模长 <0.05 rad/s 的连续静止样本（标称约 1 秒）求三轴陀螺零偏，移动会重启累计，期间不输出角度；之后依实际样本时间间隔积分并重力修正。异常/重复数据拒绝；采样间隔 >100 ms（例如浏览器处理阻塞）时重新以重力初始化姿态和 Yaw 零点，保留已经估计的陀螺零偏。Roll/Pitch/Yaw 均为角度，Yaw 为**相对值**。
- `mechanical_dog/src/UserApp/RobotApp.cpp`：10 ms IMU 轮询并维护有效姿态；串口 `rpy`/`attitude` 只读。`src/Port/DebugWebServer.cpp` 的 `GET /api/state` 返回 `attitude_ok`、角度或 `null` 及有效姿态的 `yaw_reference_ms`；`src/Port/DebugWebPage.h` 展示三个角、Yaw 零点上电后时间，无效/标定中显示“—”，说明六轴/漂移/传感器坐标系。姿态不参与舵机控制、ARM 判据仍为 IMU 新鲜度和现有安全限制。
- `mechanical_dog/test/host/host_tests.cpp` 包含静止零偏、平放、Z 轴相对 90°、横滚/俯仰、运动中重启零偏累计、无效或重复样本、时间戳回绕与长间隔归零等主机测试。主机测试和 `pio run -e esp32-c3-devkitc-02` 构建已通过，页面在模拟数据下做过桌面/手机视觉检查，且状态请求失败时仍可尝试软件 `off`；`0.3.0` **尚未烧录或经浏览器/串口实板验证**。本轮同步更新 `mechanical_dog/README.md`、`docs/REPLICA_STATUS.md`、`docs/REPLICA_PROGRESS.md`、`docs/ORIGINAL_ARCHITECTURE.md`。

## 风险与下一步

保持舵机断开，烧录 `0.3.0` 后让板子静置约 1 秒待零偏标定，然后检查网页三角与串口 `rpy`：平放静置时 Roll/Pitch 应接近零（实际芯片装贴方向待确认）；分别缓慢绕板的 X/Y/Z 轴转动，观察三角变化及轴向/符号；旋转 Z 轴后 Yaw 应表示相对转角，长时间漂移正常。比对 `imu` 原始加速度模长约 `9.8 m/s²` 和静止角速度接近零。还须观察不同浏览器刷新、较长页面请求或断线后的 Yaw 零点时间/可能归零，以及 IMU 错误时不显示过期角度，确认状态轮询不导致舵机使能或 PWM。未测定芯片传感器轴到机器人机身坐标系的安装变换、陀螺残余零偏和动态加速度误差前，不将这些姿态值接入平衡闭环；本板 `OE#` 下拉，无硬件急停，物理切断舵机供电仍必需。
