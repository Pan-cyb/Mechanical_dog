# Applepy_v1 网页控制指南（固件0.8.14）

0.8.14让前后重心/body_x与高度/Pitch/Roll使用同一实时四元组。body_x仍为−8..+8mm、step0.1、默认+8；内置Trot、Walk、trim、Trot Pitch、方向click/lease及NVS schema均不变。尚未上传或实机验收。

## 最短操作流程

1. 先断开舵机电源，把L3H插头从Servo9移到Servo13；另行授权烧录后，连接`Applepy-Debug`并确认网页固件为0.8.14、PCA和IMU正常。代码改好不代表板上已更新。
2. 首次运动必须悬空、限流，并能立即物理切断舵机V+。
3. 在控制页选择“慢速 / Walk参数 / Trot参数”；预设只改网页草稿，不应用、不保存、不运动。
4. 核对步长、抬脚和周期，点“应用其它步态参数（RAM）”。高度滑块自身走实时姿态链。
5. 点“站立”。输出关闭时它会明确执行`arm_stand`；已经使能时只执行`stand`。
6. 选择Walk/Trot后可点“开始行走”，也可点击一次前/后/左/右/原地踏步并持续运行。启动仍由固件自动完成整周期预检。
7. 点“停止”会保持最后一帧和舵机力矩；需要失力时点“关闭输出”。
8. 若要跨重启保存步态：先点“关闭输出”→确认预设/其它步态草稿→点“应用其它步态参数（RAM）”→点“保存已应用值到NVS”。实时高度已在RAM中，和其它五项一起保存；Walk/Trot共用该记录。

已有有效NVS步态值继续优先于内置Trot默认，固件不会因升级而覆盖它。点对应“Walk参数”或“Trot参数”后再点“应用其它步态参数（RAM）”；需要下次启动继续使用时再按上面的全关流程保存。

## 实时高度、Pitch、Roll、body_x

- “站高目标/down mm”滑块与原高度数字框双向同步，范围100..115、步进0.1。它实际表示髋轴到足端的向下目标；数值越大，腿目标越伸长/机身目标越低，不是外壳离地的尺量高度。
- Pitch范围−7..+5°，Roll范围−10..+10°，步进0.1。Pitch正值抬头；Roll正值左侧高。范围来自当前BodyPose/IK/map两组中位扫描，不照搬原项目25/20°。
- “前后重心/body_x mm（+向前）”范围−8..+8、步进0.1、默认+8。正值表示机身目标相对固定足端向前移动；它不是Pitch角。
- 拖动任一滑块会把当前height/Pitch/Roll/body_x完整tuple合并，在约150ms后原子发送。同一时刻只有一个请求；继续拖动只保留最新值，旧ACK不能覆盖新值。
- OFF/idle时命令只更新RAM，绝不自动ARM，因此页面会明确显示没有运动。已ARM且处于Stand/Hold时，固件从当前完整帧启动1.5s平滑Stand重定位；连续拖动可重定向当前Stand过渡。
- 硬范围不代表任意组合可达。每次四元组都走完整Stand预检；不可达时height/Pitch/Roll/body_x全部保持原值，网页回到板端读回并显示失败原因。
- 高度跨重启保存归属motion NVS，仍需全关后点“保存已应用值到NVS”；Pitch/Roll归属控制Profile，应用后在全关状态点“保存Profile”。两者不要混淆。
- 状态轮询与保存值加载会同步滑块；在途请求不会覆盖更新后的最新输入。body_x不再需要应用按钮；CG Walk开关/余量仍在高级区点“应用重心设置”，其它步态参数仍使用“应用其它步态参数”。

当前Trot默认17.9mm不是输入框30mm硬上限，也不是最新软件共同极限。按0.8.11真实模型、lift12.8、body_x8、trim0.25、两组中位、五intent和Pitch offset 0/-0.5°复核：down114共同上限18.5mm，下一档18.6因`hip_window`失败；仅前进且覆盖两种Pitch为19.8mm，仅前进/Pitch0为24.1mm。down115的共同上限为21.0mm，因此down114不是最长步长的最优down。本版不因此自动改默认；这些也只是命令模型边界，不是实物稳定或安全证明。

## Trot抬头补偿

1. 先停止到稳定Hold或保持Stand；展开运动区的“Trot Pitch补偿 °”。
2. 输入`-0.5`并点“应用Pitch补偿（RAM）”。负值表示压低前端；正值不允许。
3. 固件先按当前步态参数、八路中位、Profile、直行修正所得默认前进Trot完成整周期预检。通过后页面显示板端offset、Trot有效Pitch和revision；设置本身不发PWM。
4. 未应用草稿会锁定开始、方向和手动预检。Stop/Off不清除补偿，重启归零；“保存Profile”和“保存已应用值到NVS”都不会保存它。
5. 若页面提示`shank_map`，先确认Trot预设已是`17.9/12.8/0.5/114/0/2`。旧NVS中的13.1mm会覆盖新默认，在`-0.5°`下应被拒绝。

该补偿是开环Trot角度前馈，不读取IMU误差；高级区“移动补偿”才是Pitch误差→body_x→地面力矩的移动反馈，两者含义不同。

## 前后重心默认与Profile保存

“姿态与水平校准”里的“前后 X mm”是全局机身前后命令。`+8`在当前坐标中表示机身向机头方向前移8mm；程序等价地让四只脚在机身坐标中统一后移8mm，再做IK。它不会只降低前脚，也不会读取真实脚底压力。

网页HTML的初始框值是8，但状态首次读回后以板端RAM为准：

- 若“控制Profile”显示`nvs_missing_using_default`、`nvs_invalid_using_default`或`nvs_load_failed_using_default`，前后X应读回8。
- 若显示`loaded_nvs`且前后X为0或其他值，说明旧的合法Profile正在覆盖0.8.8内置默认；这是兼容行为，不是升级失败。

要把当前body_x/Pitch/Roll保存成以后重启仍使用的Profile：先拖动到板端已确认值 → 点“关闭输出” → 展开“高级设置与遥测” → 点“保存Profile”。无需再点姿态应用按钮；“保存已应用值到NVS”只保存含height在内的六项步态参数。保存后确认Profile状态为`saved_nvs`。

网页预检不再显示或限制峰值舵机速度。周期和1.5s过渡仍决定命令变化快慢，但真实MG90是否能跟上只能通过悬空、限流实测确认；软件通过不等于硬件无滞后或无冲击。

关页面或断Wi-Fi不会自动停止。软件“关闭输出”也不是物理急停。

点击开始后短暂显示“正在检查步态…”。这时原Walk/Trot会继续运行，Stand继续保持；ACK只代表检查已排队。只有完整检查通过、状态仍健康并收到后续新IMU样本后，才切换到新动作。检查未通过/取消会显示终态，不会迟到启动。

## 常用控制

- “直行修正”只影响普通前进/后退：0.8.11内置默认`+0.25`，前进时左右比例约为`1.00/0.75`，倒退为`-1.00/-0.75`；显式左右转和踏步不叠加trim。`+`减弱物理右侧用于纠正左偏，`−`减弱左侧用于纠正右偏。
- 手动修改仍只在RAM中，Stop/Off保留，重启恢复内置`+0.25`；不会随“保存Profile”或“保存已应用值到NVS”保存。页面静态初值为0.25，但状态轮询会以板端读回为准；未应用草稿会锁定启动。
- 左偏可能来自左右摩擦、腿中位、装配、舵机输出或载荷不一致。机器没有足压/关节/足端反馈，网页不能自动测量或求出正确值。
- 方向按钮点击一次即锁定并持续续租；“原地踏步”发送现有`step=1`意图，前后步幅为0，没有新增步态算法。点击另一方向会先结束旧session再开始新session；点击当前活动按钮或顶部“停止”结束并保持最后帧。
- 活动按钮高亮并发布`aria-pressed=true`。松开手指不会停止，也不会触发长按菜单。页面隐藏或续租网络失败会停止本地续租，固件500ms租约到期后冻结最后完整帧；租约安全语义未移除。
- Walk/Trot手动启动后持续运行，直到明确点停止、站立或关闭输出；简化网页没有改变ARM或租约规则。
- R/P/Y只显示一行姿态摘要。足端、角度和CG等原始命令遥测移到“高级设置与遥测”。
- “姿态与水平校准”默认收起。Pitch/Roll/body_x均实时；只有CG Walk enable/shift仍需在高级区明确应用。
- 静态自稳必须先稳定站立并点“水平校准”，参考就绪后再明确点“开启自稳”；网页不会后台等待后悄悄开启。

任何未应用的步态、姿态/CG或高级参数都会锁定运动启动。主界面会提示未应用项；到对应折叠区应用或放弃即可。

## 八路中位标定

1. 先点“关闭输出”，再切到“标定”，解除八处连杆受力并勾选安全确认；Stand或其他输出仍开启时，开始标定按钮会保持禁用。
2. 点“开始标定”。八路会回到当前已保存/内存中位，不会重置为固定90°。
3. 选择物理Servo接口/关节，用“中位−1° / +1°”逐路微调。
4. 点“保存并退出”会先全关，再保存八路中位并返回控制页。
5. 不保存时点“退出不保存”；全局“关闭输出”始终可用。

原始脉宽、名义角度、相对中位偏移、小腿q和单路解锁集中在“高级调试”。这些仍是台架功能，编辑、拖动、选通道和轮询本身不会输出；只有明确点击输出按钮才发送命令。

Servo13中位优先使用c12；仅c12从未保存时读取旧Servo9的c8。读取不会写NVS；以后明确保存Servo13只写c12。c12存在但非法、或旧值缺失/非法时使用90°默认，需悬空重新标定。

## 高级设置

- 步态高级项保留站姿前后、Walk轨迹偏置、手动预检和单腿测试。正常启动不要求再点一次手动预检。
- CG Walk设置与姿态共用`body_set`。修改CG开关/支撑余量后，须点同区“应用重心设置”；载入CG参数只改草稿。
- 移动补偿、planner、Pitch/Roll PD、Trot方向前馈和Profile保存/恢复均保留在高级折叠中。
- Profile、步态和八路中位仍是三份独立NVS记录；自稳开关、姿态参考、方向会话和ARM状态不会持久化。
- 高级足端/舵机角度都是命令值，不是编码器、接触或真实足端反馈。

详细几何、安全边界与原项目差异见[当前状态](REPLICA_STATUS.md)、[V10运动学](V10_KINEMATICS.md)和[迁移矩阵](MIGRATION_MATRIX.md)。

## 故障时

- 状态未知、PCA/IMU未就绪、故障或未应用草稿时，不要尝试运动。
- Walk被预检拒绝时，查看具体IK、髋窗口、小腿映射、舵机范围或支撑边距原因；载入独立“Walk参数”、显式应用后再启动，不要把Trot参数套给Walk。
- Stop/Off未确认、网络中断、异响、干涉或电压跌落时，立即准备物理切断舵机V+。
- 保存被拒绝通常表示输出尚未关闭；不要绕过门控。
