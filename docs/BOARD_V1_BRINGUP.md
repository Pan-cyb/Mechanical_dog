更新：2026-09-24。硬件依据：`../SCH_Schematic1_2026-09-24.pdf`（3 页，板名 `Applepy_v1`）。这是**原理图观察和联调计划**，不是实物电测记录；用户已拿到打样板并认为供电大致正常，但电压、电流、温升、I²C 响应、下载和舵机输出均尚无本仓库记录的实测证据。若 PCB 装配与 PDF 不一致，以逐网核对和实测为准。

2026-09-28 增补：下方“约 3 秒软件超时”是早期 `0.3.4` 及之前的台架固件行为；用户要求的本地 `0.3.5` 候选已改为手动保持直到 `OFF`，尚未烧录。最新软件风险、构建/测试及实板状态见[手动保持记录](handoff/2026-09-28_manual-servo-hold.md)。无自动超时的候选尤其需要可立即物理切断舵机电源。

## 软件分层（只引用参考项目的框架，不复制其 STM32 代码）

现已落地 [PlatformIO 工程](../mechanical_dog/README.md)：`src/main.cpp` 为组合根，使用 `Board/ApplepyV1.h` 集中引脚/地址；`include/Interface/` 定义 `IRegisterBus`、`IImu`、`IServoPwm`、`IClock`、`IConsole`；`src/Driver/` 实现 HXY IMU 和 PCA9685 寄存器协议，`src/Ctrl/` 实现命令解析、ARM/限幅/3 秒超时，`src/Port/ArduinoWireBus.cpp` 适配 Wire，`src/UserApp/RobotApp.cpp` 调度 IMU 轮询、状态与串口命令，`test/host/` 以假件测试。依赖方向是 `Application -> Ctrl/Driver -> Interface <- Port -> Arduino/ESP32`；此时没有姿态补偿、运动学或步态。当前代码启动时直接初始化预期地址并读身份，**没有通用 I²C 扫描命令**。

参考项目 `G:\PROJECT\robotic_arm\之前的工作\旧开源资料\Dummy-Robot-2.Firmware\Ctrl-Step-Driver-STM32F1-fw` 的 `UserApp/`、`Ctrl/`、`Port/`、`Core/` 只提供职责边界。Py-Apple V7.3 的 MicroPython `PA_SERVO.py`、`PA_IMU.py`、`PA_IK.py` 等提供 8DOF 行为研究，不直接复用其引脚/接口或原始 GPL-3.0 源文件。国产 IMU 另参考 `G:\PROJECT\Electronics Design Contest\the second semester of junior year\M0-chip-package\Myproj`，移植前核对具体驱动、器件身份、寄存器表和许可证。

## 逐层联调顺序与验收记录

1. **不上舵机，先测电源**：核对电池极性和 3S 范围，使用限流电源或合适保护，测 `+5V`、`5V_HOST`、3V3 的空载值与电源路径；观察发热。此步不可凭“供电应该没问题”跳过。记录仪器、电压和日期。
2. **只接 USB 下载、电脑网页/串口**：在 `../mechanical_dog/` 执行 `pio run -e esp32-c3-devkitc-02`；确认 CH340K 端口后上传。固件启动 `Applepy-Debug` 热点，电脑连上并打开 `http://192.168.4.1/` 查看状态；默认实验室密码及更改方式见工程 README。115200 串口 `help/status` 是备用诊断。若自动下载失败，排查 BOOT(GPIO9)/EN/CH340K 线路，不重复盲烧。构建通过不等于上板通过。
3. **I²C 地址与身份读取**：固件已在 GPIO4/5 对预期 `0x40`/`0x19` 初始化并读取 PCA 配置/IMU `WHO_AM_I=0x6A`，无扫描命令；若需要排查错地址，可另写独立 I²C 扫描测试。NACK、身份不符、上拉/电平异常时保持无舵机命令。`imu` 显示轮询换算后的加速度 `m/s²` 与角速度 `rad/s`，仍需与原始数据、静态重力、轴向和采样间隔核对。
4. **PCA9685 空载输出**：程序启动软件 all-off；待已确认无异常，网页选板上 Servo1 后手动使能（不发送脉冲），再点击一次发送 1500 µs，最后关闭全部输出。或从串口执行 `arm`、`pwm 0 1500`、`off`。驱动目标 50 Hz、台架限幅 1000–2000 µs；正常主循环约 3 秒软件超时，但同步网络/I²C 故障可推迟或阻止关断。用示波器/逻辑分析仪核波形并逐个记录接口；禁止把未经标定的角度直接作用到装配机械狗上。
5. **单个舵机、再逐步扩展**：断电接线、空载/脱开机构、确认舵机额定电压与电源余量，先窄范围低速动作，记录电流/压降/温升；建立每个关节的中位、方向、机械限位、通道映射。完成硬件开环证据后，才移植 8DOF 运动学/步态；12DOF 必须另有机构、编号、几何参数和 3D IK 设计。
