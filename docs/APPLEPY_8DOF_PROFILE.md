## V10 实物中位与逆解角度校核（2026-09-29，优先于下文 V7.3 历史切片）

用户确认实物使用 Structure V10 STL；八只舵机在已保存的名义 90° 中位时，侧视照片中的一条腿为**机身近水平、大腿竖直向下、小腿向左近水平**。小腿驱动舵机壳体固定在大腿上，连杆将舵盘角转换为小腿相对大腿的角度。因此保留用户当前装配；Controller V4 手册的 V7 外观照片不是 V10 中位约束。V10 `Total.stl` 是静态三角面展示件，不携带“伺服90°→关节角”的可动约束。

用户提供的逆解图中，θ₁ 是大腿方向相对**所选水平坐标轴**的角，不是舵机电气角；θ₂ 是从大腿方向延长线到小腿方向的折转角幅值，腿伸直时 0°、两杆正交时 90°。膝处两杆内角为 `180°−θ₂`，两者只有在直角时同值。设 `d²=x²+y²`、`a=l₁`、`b=l₂`，图中公式可化简为 `θ₂=acos((d²−a²−b²)/(2ab))`，与当前 `Applepy8Dof::solveLeg()` 的 `shank_deg` 以及原 `PA_IK.py` 在数值上**完全等价**。这里没有计算出小腿舵机角。

`solveLeg()` 对髋角采用镜像坐标 `u=−x, v=−y`，令 `φ=atan2(v,u)`、`δ=acos((a²+d²−b²)/(2ad))`，目前固定返回 `φ−δ` 一条折叠支路；照片的折叠方向可能需要 `φ+δ` 和配套相反符号的膝折转。用**仅供校核的 V7 名义尺寸** `a=80,b=69 mm`，把照片中位理想化为足端 `x=−69,y=−80 mm`：`φ≈49.22°`、`δ≈40.78°`、`θ₂=90°`；旧支路的髋内部角约 `8.44°`，照片支路的髋内部角为 `90°`，两种腿形可达同一足端。不能通过仅修改舵机中位掩盖逆解分支错误。当前 `toServoAngles()` 在 `hip_deg=90°` 时恰好输出保存的髋中位；因此髋公式的**零点项可能可用**，但正反方向和每腿分支仍需实物核对，不能先断言还要加一个 90°偏移。

原 V7.3 连杆函数 `C(q)=0.006649q²+0.4414q+5.53` 在 `q=90°` 时为 `99.1129°`；旧 `toServoAngles()` 会让腿1/4小腿舵机相对保存中位偏 `+9.1129°`，腿2/3偏 `−9.1129°`。这**不经过用户已确认的“舵机90°↔两杆正交”中位点**。V10 小腿舵机固定在大腿上，运动链在本地大腿坐标中是一维四杆：舵机轴 S、膝轴 K 固定，舵盘球头 A 与小腿球头 B 满足 `|A−B|=连杆球心距`。可先以中位重锚 `servo=保存中位±[C(q)−C(90°)]` 作为**纯数学候选**，但旧曲线的斜率/装配分支未证实适合 V10，不能据此开放 PWM。最终可用几何轴心/球头尺寸或安全小幅实测验证并替换曲线。

**后续纯计算增量**：`Applepy8Dof::solveLeg(..., IkBendBranch::OppositePlus)` 可明确选另一条几何折叠支路；主机测试用上述照片理想化中位，确认旧支路 `8.44°/90°`、新支路 `90°/90°`，并用正向几何检验两者足端相同。默认调用仍保持 V7.3 旧支路；`toServoAngles()` 对新支路明确返回失败，绝不让旧连杆公式把它换算成真实 PWM。`Board::kV10MotionKinematicsConfirmed=false` 是新加的独立运动锁。网页预览仍为 V7.3 参考模型，**本轮未上传、未驱动真实舵机、未声称 V10 全程映射已完成**。下一步确认四腿折叠/舵机方向、实际轴距及连杆单调范围，再实现 V10 舵机映射与有界预览。下文 2026-09-24/早期 0.3.8 记录保留历史事实，不作为 V10 已验收结论。

更新：2026-09-24。用户确认采用与 Py-Apple 相同的八自由度串联腿装配、180° MG90 舵机；拟使用新板丝印 `Servo1–4` 和 `Servo9–12` 接口。参考源码根目录：`../third_party/py-apple-servo/software/py-apple-dynamics/Py Apple Dynamics V7.3 SRC/PA-Dynamics V7.3/`。上游仓库根许可证 GPL-3.0（若干源码头与之冲突）；本地为独立 C++ 数学/寄存器实现，没有复制 Python 文件。

## 当前 C++ 切片与验收

`../mechanical_dog/include/Ctrl/Applepy8Dof.h` / `src/Ctrl/Applepy8Dof.cpp` 提供原串联腿的二维逆解、四腿对应的物理舵机角换算和八个独立的中位参数。约定 `y<0` 为足端在髋关节下方；不可达、完全伸直/折叠附近（端点各留 1 mm）、NaN、超 0–180° 的舵机角均返回失败且不写结果。采用连续的 `atan2` 取代上游 `x=0` 时的近似常数 `1.5707`，在该点与 Python 输出相差约 0.0055°。上游默认 `(0,-110)` 的 `ham≈51.32°`、`shank≈85.12°` 可作黄金算例；不应据此直接令四腿动作。

主机假件测试与 PlatformIO 编译已通过；**没有上板开环证据**。本阶段默认固件仍只暴露逐 PCA 原始通道 `pwm` 台架指令，无 IK/步态到 PWM 的路径。舵机花键安装、品牌批次、零位和实际机械止挡会改变安全范围，需要单只逐路标定。源项目 `speed=0.05`、5 ms 调度下的 TROT 相位很快，未作为 MG90 的安全步速移植。
